# Provenance and licensing decisions

The two files in `upstream/` are the exact font and license supplied for this project on 2026-10-01. Neither is normalized, reserialized, or edited.

| File | SHA-256 |

| `OFL.txt` | `b95471d27d48a9fbb4a60814272ea0acaa966be08c28ec71d55564f2f021bc7a` |

The original TTF identifies itself as Nanum Brush Script, version 1.100, with 13,799 glyphs and 11,789 Unicode mappings. Its English copyright field reads: “Copyright © 2010 NHN Corporation. All rights reserved. Font designed by Sandoll Communications Inc.” Its designer field credits Kwak Doo-yul and Nicolas Noh. There are no Cyrillic cmap entries.

The supplied OFL names NHN Corporation as the original copyright holder and declares the Nanum family of Reserved Font Names. Talyn Brush preserves those notices. The primary family, full, unique, typographic, compatible, WWS, and PostScript names are replaced; the old names survive only where needed for attribution/trademark/license history. The root OFL adds a derivative copyright statement and preserves the license body unchanged. No new Reserved Font Names are declared.

Every TTF and WOFF2 embeds the full root OFL in name ID 13 and retains the original copyright and trademark credit. The distributable ZIP includes OFL.txt, FONTLOG.txt, and the unmodified OFL FAQ. The original files are publicly redistributed under their original OFL names only in `upstream/`.
