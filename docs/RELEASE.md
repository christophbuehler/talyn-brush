Talyn Brush 0.100 adds the full Mongolian Cyrillic alphabet to an independently renamed derivative of Nanum Brush Script.

- 70 Cyrillic letters, including Өө and Үү; 74 new Unicode mappings in total.
- All 11,789 original mappings and every original glyph outline and metric preserved.
- TTF and WOFF2 with embedded SIL OFL 1.1; attribution, font log, design notes, and original license included in the ZIP.
- CI builds, tests, sanitizes both formats, checks reproducibility, and renders all 11,863 characters.

[Try it](https://christophbuehler.github.io/talyn-brush/) · [Complete character atlas](https://christophbuehler.github.io/talyn-brush/specimen/all-characters.png)

This is a **preview**. Independent native Mongolian/type-designer review is still welcome. Traditional vertical Mongolian is outside this release’s scope. No endorsement by the original font authors is implied.

Download the ZIP and verify it against `SHA256SUMS.txt`. Install the TTF or self-host the WOFF2 with its license.
